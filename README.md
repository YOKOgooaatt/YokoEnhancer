# YokoEnhancer Download Page

A responsive, animated, black liquid-glass landing page for YokoEnhancer. Built with plain HTML, CSS, and JavaScript for free static hosting on GitHub Pages.

## Included
- Animated edge glow, glass panels, gradients, particles, floating UI artwork, scroll reveals, and responsive navigation.
- Clearly visible **COMPLETELY FREE TO USE** messaging and **Made by Yoko** footer credit.
- PC performance notice for CPU, RAM, and GPU expectations.
- Download button linked to the supplied Google Drive installer.
- Secondary Google Drive file-page link in case direct download prompts need confirmation.

## Publish on GitHub Pages
1. Download and unzip this ZIP.
2. Open your GitHub repository for the website.
3. Upload **all files inside** this folder to the repository's top level (especially `index.html`, `style.css`, `script.js`, and `.nojekyll`).
4. Commit the files.
5. In the repository, open **Settings → Pages**.
6. Under the build/deployment settings, choose **Deploy from a branch**, select `main` and `/(root)`, then save. If the repository UI offers a GitHub Actions option instead, follow the Pages workflow prompt.
7. Wait for the deployment to finish. GitHub will show the published URL in **Settings → Pages**.

For a project repository, the URL usually looks like `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.
